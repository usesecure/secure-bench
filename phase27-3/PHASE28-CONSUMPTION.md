# Phase 28 consumption

Before its irreversible marker, Phase 28 must load `phase27-3/binding-overlay.json` after Phase 27.1 and Phase 27.2. It must invoke the OpenGrep and Semgrep runners as separate processes after receiving raw scanner JSON. A runner receives only the frozen request document and emits only the historical normalized public projection.

Phase 27.3 governs the complete multi-adapter Cargo composition. Phase 27.2 remains a valid historical OpenGrep certification but is superseded for multi-adapter composition. Phase 27.1 remains authoritative for scanner executables, rulesets, sandbox, environment, resource limits, and every binding outside the three historical Cargo packages and two runners.

A runner failure belongs to the current Phase 28 attempt. It never authorizes another scanner execution. This certification does not authorize opening Phase 28 or altering its 336-attempt plan.
