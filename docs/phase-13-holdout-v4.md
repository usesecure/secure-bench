# Phase 13: prospective holdout v4

Phase 13 authors and cryptographically freezes a new Secure Bench 0.2.1 examination. It contains
56 independent vulnerable/control pairs and 112 total cases. Every case is intentionally
unexecuted and outside scanner scoring until a separately authorized one-shot evaluation phase.

The holdout uses taxonomy 1.0.0, Evidence Contract v2, the Phase 12 adapter-precedence and
holdout-authoring policies, the Phase 12.1 historical boundary, and the existing process-status
policy. Expectations remain outside scanner-visible fixture directories. A future runner may copy
only one neutral fixture directory into an isolated scan workspace.

The schedule contains eight pairs per taxonomy family and fourteen pairs per framework, source
format, and topology. JavaScript and TypeScript language groups contain twenty-eight pairs each.
Every 4x4 pairwise factor table has three or four pairs per cell; exact equality is impossible
because 56 divided by 16 is 3.5.

The manifest records adversarial coverage independently of the answers. The design includes
destructuring and aliases, local and inter-file helpers, multiple-argument wrappers, control-flow
joins, authentication-versus-authorization distinctions, ownership/tenant/role checks,
non-dominating and non-terminating guards, sibling-prefix and hostname-suffix near misses, URL
protocol and user-info constraints, redirect fallbacks, fixed executables with argument arrays,
parameterized SQL, dynamic-code aliases, ambiguous resolution, recursion, and conservative
unsupported boundaries.

Vulnerable members contain a concrete externally controlled source, connected value flow, exact
source and sink spans, and a realizable Evidence Contract v2 path without an effective barrier.
Controls retain the source, value identity, topology, and sensitive-operation shape while adding a
terminating sink-dominating authorization decision, exact destination or path policy, allowlist,
safe process API, or structural parameterization.

Validation reconstructs every byte and rejects taxonomy drift, legacy precedence, disconnected
paths, invalid spans, weak controls, mutation drift, duplicates, historical copying, symlinks,
path traversal, answer leakage, commitment drift, ledger rewriting, and factor imbalance. Exact
hash and normalized token five-gram overlap measurements are reproducible proxies; they are not
proof of semantic independence.

No Secure Engine source or binary was inspected or executed. No scanner, AI provider, network AI
call, result, or score is part of this phase. This holdout does not support rankings, superiority,
production-readiness, or complete-coverage claims.
